# SHIELD

**Ship Hull Inspection on Edge with vision-Language model & Drones**  
**DualBrain · 선박 도장 검사 연구 프로젝트**

SHIELD는 도장면의 스크래치를 휴대폰에서 찾아내고, 확인된 검출 결과와 문헌 근거를 검사 보고서로 연결하는 시스템을 연구합니다. 휴대폰을 드론에 탑재하는 촬영 방식까지 목표로 하되, 먼저 손에 들고 촬영하는 조건에서 동작을 확인합니다.

## 무엇을 확인하려 하나요?

- **현장에서 찾기:** YOLO 기반 탐지 모델을 휴대폰에서 실행해 스크래치 검출과 처리 지연을 측정합니다.
- **근거를 구분해 설명하기:** 언어모델(LLM)과 지도 미세조정(SFT)을 검토하고, 관찰 사실·문헌 근거·확인되지 않은 추정을 구분한 보고서를 만듭니다.
- **학습 방식 비교하기:** 개별 학습, 통합 학습, 연합학습(FL)을 같은 조건에서 비교합니다. 가상 환경의 비교와 실제 기기에서의 검증을 구분합니다.
- **촬영부터 보고서까지 연결하기:** 휴대폰 촬영·탐지·결과 전송·보고서 생성 흐름을 확인한 뒤 드론 탑재 시험으로 확장합니다.

## 현재는 어디까지 진행됐나요?

**아직 완성된 제품이나 검증된 검사 서비스가 아닙니다.** 이 저장소의 첫 공개본에는 프로젝트 소개와 연구 계획만 담았습니다.

2026년 10월 26일 기준으로 스크래치 원본 사진과 라벨 **156쌍**의 저장·무결성 검증 기록을 확보했습니다. 정상 사진은 아직 **0장**입니다. 시각언어모델(VLM)을 이용한 데이터 적합성 검수 결과는 **52장**, 이 중 채택 후보는 **30장**입니다. VLM은 현재 데이터 선별을 돕는 용도이며, 제품의 진단 기능이 완성됐다는 뜻은 아닙니다.

학습 승인, 독립 평가, 휴대폰 성능 측정, 드론 비행 검증은 별도로 필요합니다. 사진·라벨·모델 파일과 실행 코드는 이 초기 공개본에 포함하지 않습니다.
