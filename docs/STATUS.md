## 아직 확인해야 할 내용

- 원천 자료 전체의 완전성, 정상·반사·이음매 등 어려운 음성 사례 확보

- 실제 사진을 이용한 학습 결과와 같은 조건의 개별·통합·연합학습 비교
- 모델 변환 전후 결과, 실제 휴대폰의 정확도·지연·메모리 측정
- 검수된 문헌과 문답 자료, 설명의 근거 일치·불확실성 표시 평가

## 다음 단계의 완료 기준

1. **데이터:** 정상 사진을 포함한 검수 묶음과 장면 단위 분할 목록을 준비합니다.
2. **기본 모델:** 첫 실제 학습을 마치고 탐지 성공·오탐·미탐을 같은 평가 조건으로 기록합니다.
3. **휴대폰:** 선택한 기기에서 변환 모델을 실행하고 처리 지연과 실패 사례를 측정합니다.
4. **보고서:** 검출 사실, 참고 문헌, 확인이 필요한 내용을 구분해 실제 입력과 대조합니다.
5. **비교와 시연:** 학습 방식 비교와 손촬영 전과정을 확인한 뒤 드론 탑재 시험 범위를 정합니다.

중간발표에는 실제로 확인한 결과와 미완료 항목을 함께 제시할 예정입니다. 현재 공개본에는 정확도·속도·비행 성공에 대한 달성 수치를 제시하지 않습니다.
